Auth #

POST /auth/register
Yeni kullanıcı kaydı ve JWT üretimi.
Auth
Gerekmez
Body
{
  "email": "a@b.com",
  "username": "alice",
  "password": "secret123",
  "role": "CREATOR" // optional, allowed: USER|CREATOR, default USER
}
Yanıt
{
  "token": "",
  "user": { "id": "...", "email": "a@b.com", "username": "alice", "role": "CREATOR" }
}
GET /auth/me
Kimliği doğrulanmış kullanıcının profilini döner.
Auth
Bearer <JWT>
Yanıt
200 · { id, email, username, role, createdAt }
POST /auth/change-password
Eski ve yeni parola ile şifreyi değiştirir.
Auth
Bearer <JWT>
Body
{
  "oldPassword": "secret123",
  "newPassword": "newSecret456"
}
Yanıt
{ "ok": true }
POST /auth/login
Giriş yap ve JWT al.
Auth
Gerekmez
Body
{
  "emailOrUsername": "alice",
  "password": "secret123"
}
Yanıt
{
  "token": "",
  "user": { "id": "...", "email": "a@b.com", "username": "alice", "role": "CREATOR" }
}

Posts #

POST /posts
Yeni post oluştur. Sadece CREATOR/ADMIN.
Auth
Bearer <JWT> (CREATOR/ADMIN)
Body
{
  "title": "İlk postum",
  "content": "Merhaba!",
  "isSecret": false,
  "mediaUrl": "https://cdn.example.com/p.jpg",

Yanıt
201 · Post

{

Notlar #

  • Gizli (isSecret: true) postlar, sadece yazarını takip eden kullanıcılarca görüntülenebilir.
  • Reactions (like/save) gizli postlarda da aynı erişim kuralını uygular.
  • postId ve userId alanları cuid formatındadır.
  • Varsayılan header: Authorization: Bearer <JWT> olarak Postman environment'ta ayarlanabilir.
  • Sunucu JSON body limiti: 5 MB. CORS originleri CORS_ORIGINS env değişkeniyle yönetilir.
